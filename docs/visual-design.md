# 丰缘像素视觉与地图约定

## 素材优先级

2026-10-21 的改造以复用 GBA 原作像素为主。此前程序化绘制覆盖 vendor 地形、NPC 自绘优先、人物抽行压缩的路径已修正。地图布局属于本项目；地形、建筑、人物、宝可梦和普通道具尽量使用原作素材。GPT Image 用于缺少合适图标的跑鞋，以及项目专用的登录/注册场景。

1. 世界与人物：经 sha256 校验的 `public/assets/vendor/world/` 原作素材优先；对应资源缺失或校验失败才用程序化回退。
2. 普通道具与宝可梦：继续使用 `scripts/fetch-assets.mjs` 下载的 PokeAPI 素材。
3. 跑鞋和欢迎插画：使用 `public/assets/generated/` 已入库 PNG；原始生成文件和完整提示词在 `frontend/art/`。

## 原作资源管线

`frontend/tools/build-world-assets.py` 从 [pret/pokeemerald](https://github.com/pret/pokeemerald) 的固定提交 `731ad5bfd6e6f265508d0efcca0ba42f9dcf5881` 解码图片，缓存位于 `~/.cache/pokechain-world/<revision>/`。可用 `--source /path/to/pokeemerald` 读取同版本本地源码；默认输出路径相对于脚本确定，不依赖工作目录。

- metatile 为 16×16，由两层各四个 8×8 子块组成；分别按 512 边界选择主/副瓦片库、按 6 边界选择调色板，应用水平/垂直翻转及上层透明色。原始像素最近邻放大 2 倍。
- 5 张多行图集覆盖 14 种 biome；`manifest.json` v2 记录完整瓦片索引、道路/沙地/水岸的 3×3 过渡块、图像 sha256 和上游版本。原作水面与岩浆动画目前使用首帧，尚未实现动态播放。
- 51 张独立图片：男女主角两张、9 类 NPC 各四向加默认站姿（45 张）、3 种整栋建筑、1 张草地战斗背景。
- 原作人物保留完整 16×32 帧，整数放大为 32×64；不再删行压成方形。主角 3 列×4 行（96×256），所有帧使用同一脚底基线；向右由原作向左帧镜像。护士原作没有四向行走帧，因此四向均用正面站姿。
- 原作资源输出仍在 gitignore 内。脚本、映射与来源入库，干净 clone 后运行脚本恢复资源。

## 世界绘制

`native-map.ts` 产出原作图片裁切/拼接命令，游戏与预览页共用；`world-art.ts` 只生成并缓存 Phaser CanvasTexture。已映射的地形不再被自绘矩形覆盖。道路、沙地、水岸、岩壁按邻接关系选择原作子块；海域统一使用原作波纹。洞窟地面、火山岩、岩浆与桥面按实际语义选择，避免把台阶/晶石/岩壁当成平地。

树木使用原作 2×2 组合，必须完全落在四个阻挡格内，窄处使用完整原作灌木。建筑由门对象定位：中心/商店 4×4，民居 5×5；保留原作屋顶、门窗与招牌，没有拉伸。未白镇同步调整建筑碰撞格，门口落点不变。塔柱将原作石柱前景叠到塔内地板上；人物按脚底对齐并按所在行排序深度。

`character-art.ts` 和 `world-textures.ts` 保留作为离线缺图回退，不是正常演示的美术来源。BootScene 兼容旧版 32×32 主角与 32×40 自绘回退。战斗使用原作 240×112 草地背景，按整数 4 倍显示；前后视角宝可梦仍用原始 sprite，状态框沿用统一主题。

## GPT Image 补充素材

| 用途 | 运行时文件 | 处理 |
|---|---|---|
| 跑鞋道具 | `frontend/public/assets/generated/items/running-shoes.png` | 32×32，透明底、24 色、硬边 alpha |
| 登录/注册欢迎场景 | `frontend/public/assets/generated/ui/hoenn-welcome.png` | 384×256，64 色，3:2 比例 |

生成要求是第三世代 GBA 像素风：有限调色板、清晰像素簇、分层明暗、小尺寸轮廓可辨。生成后仅用 ImageMagick 最近邻采样和限色适配，不以 SVG/Canvas 重画。`frontend/art/prompts.json` 保存实际提交的完整提示词、源文件、产物及处理参数，后续调整可追溯。

## 界面与布局

字体沿用自托管 Press Start 2P 与 Fusion Pixel。主题在 `frontend/src/styles/pixel.css`：湖蓝灰边框、暖白面板、草绿主操作与浅绿页面背景。间距按 4px 网格，按钮和输入框至少 44px 高。导航使用 `PixelIcon`；`ItemArtwork` 仅在图标缺失时回退。

登录/注册插画在桌面最大 480px、小屏最大 384px，保持 3:2。队伍/图鉴共用 collection 布局，商店沿用货架卡片，背包窄屏可横向滚动。焦点管理、减少动态效果偏好、世界 HUD 避让和游戏保活沿用现有实现。所有页面路由不变。

除未白镇建筑占地适配与天空之柱留出柱间空隙外，15 张地图沿用既有连通性、传送、遇敌和钥匙规则。妈妈仍在 `(9,18)` 面向南，南方孤岛返航东侧码头、诞生岛返航西侧码头。
