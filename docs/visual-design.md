# 丰缘像素视觉与地图约定

## 视觉系统

前端沿用自托管 Press Start 2P 与 Fusion Pixel 字体。统一的主题在 `frontend/src/styles/pixel.css`：湖蓝灰文字/边框 `#354f5c`、暖白面板 `#faf8e9`、草绿主操作 `#357966`、浅绿底页 `#dce7d5`、暖黄积分提示 `#f0cd79`。间距按 4px 网格，常用 8/12/16/24px；主按钮和输入框至少 44px 高。选中态使用浅绿底与深绿边线，同时通过 `aria-pressed` 暴露选择状态。

导航分为训练家信息栏与可横向滚动的功能菜单。`PixelIcon` 提供统一的像素轮廓。登录与注册共用训练家卡片布局，自绘场景在 `frontend/public/assets/ui/hoenn-postcard.svg`，可以入库，不依赖 vendor 下载。

队伍和图鉴复用 `.collection-*` 布局：常规网格、360px 详情栏、小屏详情移到列表上方。商店使用统一间距的货架卡片；背包表格在窄屏横向滚动。对话框使用暖白双线内框、键盘焦点限制与关闭后焦点归还。CSS 动效遵循系统减少动态效果偏好。

## 世界绘制

`frontend/src/game/world-art.ts` 在每张地图首次进入时生成一张 CanvasTexture，16px 逻辑网格按 2 倍绘制。缓存随 Phaser 实例销毁。邻接关系决定道路边线、水岸、岩壁外缘与栈桥边柱；同一种地形内部不重复画边框。草地采用稀疏确定性草尖，深草保留清晰的草叶轮廓，不再整片呼吸闪白。不同生物群系沿用 `BIOME_COLORS`。

建筑以 `door` 对象为锚点读取连续屋顶占地，绘制完整屋脊、屋檐、外墙、窗户和门。中心红顶、商店蓝顶、民居棕顶；招牌落在屋檐区域。外观绘制不另建碰撞层，`maps/query.ts` 仍以原语义网格及 NPC 占位决定通行。旧 vendor 素材加载/校验协议保留，楼梯、柜台、石柱等未重绘语义继续读取合成瓦片。

`character-art.ts` 是自绘人物公共绘制器，16×20 逻辑像素、四个方向，职业服装与背包分别着色。NPC 优先使用四向自绘纹理，角色脚底统一锚定逻辑格下沿，以所在行排序深度。自绘主角每帧 32×40，四方向三帧；BootScene 仍兼容原有 vendor 32×32 主角帧。

道具仍优先读取本地 vendor 图片，失败时使用 `ItemArtwork.vue` 的 30px 自绘图标，区分球、药、进化石、技能机、糖果、王冠、钥匙和跑鞋。宝可梦展示保留原始素材、整数缩放与缺图回退。

## 地图布局

- 未白镇：两条横街与中央主街相连，中心/商店有三格宽门前庭院；民居为五格宽，水塘移入西侧庭园；妈妈位于 `(9,18)`，面向南方，门口不再被 NPC 挡住。
- 森林：东侧支路形成环线，把研究员附近与深草探索区连接回主路。
- 104 号道路：桥南新增步道，遗迹门前显式保留两格宽入口。
- 洞窟：入口、北侧楼梯与两厅由两格宽石道连接，保留两侧碎石遇敌区。
- 海岸：滨海道路连接两座码头；海蚀洞有明确岩体；孤岛落点与码头显式连通。南方孤岛返航回东侧码头，诞生岛返航回西侧码头。
- `road()` 的点表示走廊左上角，拐点覆盖 `width×width`；不再向最小坐标外多挖一格。地图有门口延伸需求时显式铺设，避免依赖隐式越界。
